## Caller-supplied displayed variant integrity (2026-11-01, Track A)

- The existing `EvaluateSnapshot` rejects duplicate article IDs, but `EvaluateChoice` and `ResolveChosenVariant` accepted arbitrary caller-supplied displayed `IList` values without checking unrelated duplicate/malformed entries.
