# نسخ LOGICA الاحتياطي ومسح الجداول المحددة

## سبب الإصلاح

كان Button9_Click يرسل BACKUP DATABASE ... TO DISK إلى MySQL، وهي صيغة SQL Server. وكان يعالج فشل حذف جدول داخل catch ثم يعرض رسالة النجاح خارجها. الإصلاح في السورس الأصلي وليس في نسخة بناء مؤقتة.

وجدت الصيغة نفسها في النسخ اليدوي ونسخ ما قبل الإطفاء. كان مسار الإطفاء يتجاهل خطأ النسخ ويواصل إطفاء الحاسوب. أصبحت المسارات الثلاثة تستعمل الآلية نفسها؛ يمنع الإطفاء عند فشل نسخة طلبها المستخدم، ويحافظ على خيار الإطفاء دون نسخ إذا لم يطلب المستخدم النسخ.

DatabaseBackup يستعمل mariadb-dump أو mysqldump من مسار LOGICA_MYSQL_BIN أو خادم الحزمة المحلية. ينشئ dump SQL كاملاً مع triggers وroutines وevents وviews وبيانات binary، ويتحقق من خروج الأداة وعلامة اكتمال dump، ثم يثبت الملف وبصمة SHA256. بيانات الدخول تمر بملف مؤقت ذي ACL للحساب المنفذ، وتزال في finally؛ لا تمر كلمة المرور في arguments.

## حدود المعاملة والتزامن

تتحقق العملية من أسماء الجداول الموجودة فعلاً ومن InnoDB لكل جداول القاعدة. داخل معاملة RepeatableRead تنفذ مسحاً كاملاً FOR UPDATE لكل جدول، بما في ذلك الجداول الفارغة. تبقى أقفال الصفوف وفجوات الإدخال حية أثناء قراءة أداة النسخ snapshot مستقلة بـsingle-transaction ودون table locks. يبدأ حذف الجداول المختارة بعد اكتمال النسخة وبصمتها فقط، وفي المعاملة نفسها. أي فشل يعيد كل الحذف. تبقى النسخة المكتملة متاحة إذا فشل الحذف لاحقاً.

هذا مسار صيانة قد يجعل الصناديق الأخرى تنتظر خلال النسخ. لا يستخدم على محرك غير InnoDB؛ يرفضه قبل المسح. لا تعطل FOREIGN_KEY_CHECKS؛ إذا منعت العلاقات حذف الجداول المختارة، تتراجع العملية وتحتفظ بالنسخة. إعدادات TLS التي تفرض تحققاً خاصاً تتطلب تهيئة منفصلة للأداة؛ لا يخفضها المسار بصمت.

النسخ اليدوي يحفظ الاسم الذي اختاره المستخدم بصيغة .sql مع بصمته، ويرفض استبدال نسخة موجودة. لا يسمي SQL بامتداد .sni حتى لا تختلط مع استيراد Access القديم. لم يغيّر مسار استيراد ملفات Access القديمة في هذه الدفعة.

## نسخ مستقل دون مسح

بعد إغلاق تشغيل LOGICA المحمول، يشغل Backup-LOGICA.cmd المشغّل نفسه مع BackupOnly، ويبدأ الخادم المحلي وLOGICA.Backup.exe ويوقف الخادم بعد الانتهاء. يحتفظ بالنسخ في bd/backup. لا يغير قيد الاستيراد ولا يستبدل قاعدة موجودة. يمكن استعمال هذا المدخل من مجدول مهام Windows تحت الحساب الذي يملك إعدادات التشغيل المحلية. لا تنفذ هذه الدفعة جدولة على جهاز التاجر عن بعد.

النسخة SQL غير مشفرة؛ ينبغي حفظها ونسخها إلى وسيط احتياطي وفق صلاحيات وسياسة المتجر. SHA256 يكشف التغيير في الملف ولا يغني عن استعادة تجريبية. الاستعادة لا تنفذ فوق قاعدة التاجر تلقائياً.

## تحقق Windows الآلي

scripts/test-database-backup.ps1 يهيئ قاعدة منفصلة من snapshot LOGICA الأصلية، ويضيف fixtures للغة العربية والاقتباس وNULL وbinary وتاريخ ناقص ومبالغ كسرية، وview وroutine وtrigger وevent. ينشئ النسخة عبر الكود المبني، ثم يستعيدها على خادم MariaDB ثانٍ معزول على 3309 باسم القاعدة نفسه، حتى لا تخفي إعادة تسمية القاعدة مراجع views المؤهلة.

المقارنة تفحص أعداد الصفوف وCHECKSUM TABLE EXTENDED وتعريفات CREATE TABLE لكل جدول، ووجود الكائنات الإضافية وعمل view وroutine. تختبر كذلك SHA256 بعد التلاعب، غياب الأداة، اسماً غير موجود، محركاً غير معاملاتي، خروج الأداة بفشل، ملفاً ناقصاً مع exit=0، إزالة ملفات الدخول المؤقتة، وفشل الحذف في الجدول الثاني مع التراجع عن الأول. يستدعي الاختبار طريقة التنفيذ في نموذج LOGICA الأصلي؛ لا يتجاوز تأكيد المستخدم في مسار الواجهة.

اختبار التزامن يوقف exporter عند بوابة بعد الأقفال، ويتأكد أن تحديثاً مستقلاً وإدخالاً في جدول فارغ ينتظران، ثم يستأنفان بعد المعاملة. يفحص الاختبار مسار النسخ اليدوي في النموذج، وحفظ الاسم، ومنع استبدال نسخة سابقة. ويفحص ترتيب النسخ والإطفاء والخروج بأفعال بديلة، ولا يطفئ جهاز CI. تستعاد نسخته أيضاً للتحقق أن الكتابات اللاحقة ليست داخل snapshot. تشغل CI كذلك مدخل BackupOnly للحزمة المحمولة. ملفات SQL التجريبية وبيانات الخادم لا تدرج في حزمة التسليم؛ تحفظ ملخصات التشخيص فقط.

[الأدلة المقروءة آلياً](backup-ci-evidence.json) و[مصفوفة مسارات النسخ](backup-feature-status.csv). لم تختبر هذه الدفعة استعادة على تثبيت متجر حي أو محركات غير InnoDB أو وسائط تخزين احتياطي خارجية.

ملف SQL لا يشمل ملفات صور المنتجات أو إعدادات الجهاز خارج القاعدة؛ النسخ الشامل لهذه الملفات ما زال مطلوباً. لم تختبر تغييرات DDL متزامنة أثناء الصيانة. تحقق SHA256 وبصمات الجداول لا يمثل تشفيراً أو ضماناً على عتاد التخزين.
